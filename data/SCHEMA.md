# مخطط data/diwan.json

هذا الملف هو قاعدة بيانات الديوان الكاملة — يقرأه كل من `scripts/generate_pages.py` (يبني الصفحات الثابتة) و`js/app.js` (الصفحة الرئيسية التفاعلية) و`add-poem.html` (أداة الإدارة). أي حقل جديد يُضاف هنا يحتاج تعديلاً في **الثلاثة** غالباً — راجع القسم الأخير.

## البنية العامة

```json
{
  "site": { "subtitle": "...", "footerNote": "..." },
  "roleLabels": { "بدع": "بدع (أصلية)", "رد": "ردّ", "مجاراة": "مجاراة" },
  "poets": [ /* شعراء آل السويلم */ ],
  "externalPoets": [ /* شعراء خارجيون مرتبطون بالديوان عبر رد/مجاراة */ ]
}
```

## `poets[]` مقابل `externalPoets[]`

- **`poets[]`**: شعراء أسرة آل السويلم فقط. لهم صورة (`photo`) ووسم (`wasm`) ونبذة (`bio`)، ولهم صفحة مستقلة بفهرس الشعراء (`/poets/<id>.html`).
- **`externalPoets[]`**: شعراء من خارج الأسرة، يظهرون بالديوان **فقط** لأن قصيدة لهم مرتبطة برد/مجاراة من أحد آل السويلم (أو العكس). لا صورة ولا وسم ولا صفحة مستقلة — تظهر قصائدهم فقط ضمن صفحة "شعراء تجاوبوا مع الديوان" (`/respondents.html`) وكجزء من سلسلة الرد/المجاراة.

**قاعدة الإدراج**: شاعر خارجي لا يُضاف إلا لو كان هناك رابط رد/مجاراة فعلي (`role` + `mujarat.respondingToId`) يربطه بآل السويلم — إما قصيدته هو رد/مجاراة على قصيدة من الأسرة، أو قصيدة من الأسرة رد/مجاراة عليه. شاعر خارجي بلا أي رابط كهذا يُحذف (حصل هذا فعلياً بمخلد بن هليل وقصيدة سعد الامهود المرتبطة به، حُذفا لعدم وجود رابط).

## حقول الشاعر (`poets[]`)

| الحقل | إلزامي | النوع | المعنى |
|---|---|---|---|
| `id` | ✓ | string | `poet-N` — رقم N هو أعلى رقم موجود حالياً +1، **وليس** عدد الشعراء+1 (تجنّباً لتصادم بعد حذف شاعر من المنتصف). |
| `name` | ✓ | string | الاسم الكامل. |
| `photo` | — | string | مسار صورة (اختياري — شاعر بلا صورة يظهر بوسم مثلث ▲ بديل). فضّل صورة مصغّرة (WebP، ~160px) لا الأصل الكامل. |
| `wasm` | — | string | معرّف أيقونة SVG بديلة (`wasm-1`..`wasm-5`، معرّفة بـ`js/app.js` وWASM_OPTIONS بـ`add-poem.html`) — تُستخدم فقط لو لا توجد `photo`. |
| `bio` | — | string | نبذة قصيرة. "قيد الإضافة" = لم تُكتب بعد (نص مؤقت، ليس نبذة فعلية). |
| `poems` | ✓ | array | مصفوفة قصائد الشاعر — انظر أدناه. |

## حقول القصيدة (`poems[]` داخل أي شاعر، عائلي أو خارجي)

| الحقل | إلزامي | النوع | المعنى |
|---|---|---|---|
| `id` | ✓ | string | `<poet-id>-poem-N` — نفس قاعدة تفادي التصادم (أعلى رقم +1). |
| `title` | ✓ | string | عنوان القصيدة. **إذا لم يُذكر عنوان حقيقي بالمصدر** (صورة/تغريدة/ملف)، يكون العنوان = صدر البيت الأول حرفياً — لا يُختلق عنوان وصفي. |
| `role` | ✓ (قد تكون `""`) | string | `""` (قصيدة عادية/أصلية بلا علاقة رد) \| `"بدع"` (أصلية بدأت مساجلة) \| `"رد"` \| `"مجاراة"`. النصوص المعروضة لكل قيمة مصدرها **حصراً** `roleLabels` بأعلى الملف — لا تُكرَّر كنص حرفي بأي كود. |
| `mujarat` | — | object | موجود فقط لو `role` رد/مجاراة: `{respondingToPoet, respondingToTitle, respondingToId}` — `respondingToId` يشير لمعرّف القصيدة الأصلية (لازم يكون معرّفاً موجوداً فعلياً، `generate_pages.py`'s `validate_data()` يتحقق من هذا ويوقف البناء لو كُسِر). |
| `meter` | — | string | البحر/الوزن الشعري. |
| `date` | — | string | تاريخ القصيدة (نص حر، غالباً سنة). |
| `source` | — | string | مصدر النقل (صورة أرشيف، تغريدة، "الشاعر" مباشرة، إلخ). |
| `occasion` | — | string | مناسبة القصيدة (حدث/إهداء/رثاء إلخ) — **اختياري تماماً**؛ اتركه غير موجود (لا تكتب نصاً ينفي وجود مناسبة) إذا لا تنطبق، فيختفي الحقل تلقائياً من صفحة القصيدة. |
| `verses` | — | array | `[{sadr, ajz}, ...]` — قد تكون غائبة لقصيدة معروفة بالاسم لكن أبياتها غير محفوظة بعد (تظهر رسالة بديلة بالصفحة). |
| `addedAt` | — | string | تاريخ الإضافة (`YYYY-MM-DD`) — تُستخدم لقسم "أضيف حديثاً" بالصفحة الرئيسية وترتيب sitemap. |

## إضافة حقل جديد لقصيدة — نقاط التحديث المطلوبة

جرّبنا هذا فعلياً بحقل `occasion` وسبّب خللاً لأن نُسي أحد الملفات. عند إضافة حقل جديد، حدّث:

1. `scripts/generate_pages.py` → `poem_info_html()` (قائمة `fields`).
2. `js/app.js` → `poemInfoHtml()` (قائمة `fields` المطابقة).
3. `add-poem.html` → حقل الإدخال بنموذجي الإضافة والتعديل + `buildPoemData()`/`applyToLocalDiwan()`/`publishEdit()`.

## إضافة نوع "دور" (`role`) جديد غير رد/بدع/مجاراة

يحتاج تعديل 4 مواضع (لا مصدر حقيقة واحد لها حالياً، خلافاً لنصوص التسميات):
1. `roleLabels` بـ`data/diwan.json` (نص حقل "النوع").
2. `ROLE_LABELS`/`ROLE_BADGE_TEXT` (تنسيق الشارة الملوّنة) بـ`js/app.js` و`scripts/generate_pages.py`.
3. `css/style.css` → قاعدة `.role-<الاسم>` جديدة للون الشارة.
4. `add-poem.html` → زر `role-pill` جديد + قاعدة CSS `active-<الاسم>`.
