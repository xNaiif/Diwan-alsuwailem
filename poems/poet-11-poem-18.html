من يقول الورد يجرح خآطر الهواوي

محمد ضيف الله بن سويلم العتيبي
من يقول [ الورد ] يجرح خآطر الهواويشاف ( مما عاف ) حتى عاف شوف عيونه
كيف يرضى الورد يهدى للملي والخاوي ؟سنةٍ ماهيب في { سلم الهوى } مسنونة
وكيف يقنع قلب [ لو يذبح ] ما أخذ رشاويولا قبل بالواسطة لو ضيّقوا به كونه
الهوى له سلم { وأحكام الهوى} ماتاويمن قبل وقت الملوّح ( ثابتٍ ) قانونه
الهوى محدٍ تحكّم به ولاحدٍ قاوي[ يكبح ] جنون المشاعر لو تزيد جنونه
الهوى لو غير شوفك له طبيب مداويكان يمدي شهار به نصف العرب مسجونة
والهوى اللي يطرح الرجل القوي متساويلا صحيح ولا عليل ولا عرفت اشلونه
والهوى اللي لا سمعت بديرتك من راويهيّض الخفّاق (طرياها ) وجر لحونه
ماهويت الدار لو انّه [ مكاسر جاوي ]حبها من حب من فيه العرب مفتونة
[ ساحرٍ ] لو انشد اهل الدين والفتاويحلّلوا سحر مكانه { شفتيه ونونه }
[ راميٍ ] مدّة عيونه تفقر الغناويوتغني الفقران لو زادت عليه ديونه
تحفة وقمة جمالٍ ما لمحها غاويمكتنزها وسط ( لوفر ) قلبي ومرهونة
راهنٍ روحٍ [ تمنّت ] وأعظم المناويفرحته في دنيته تزهى بضحك سنونه
كم مشيت وكم مشيت وطالت الخطاويوالسراب ازرى يفارق واقفٍ من دونه
فدوتك قلبٍ { من القمة } سقط متهاويمن ( حزامك ) بعد ما كان الحزام يصونه
روح وانا بخير لو حالي ماهو متشاويلو فؤادي من بعادك كاثرات طعونه
[ جر صوتك ] يا خفوقي مثل ذيبٍ عاويوين أبلقى درّة فالمملكة مدفونة
